SWAPNAMAYEE DAS — PERSONAL PORTFOLIO

FILES
- index.html: page content
- style.css: layout, colors and responsive styling
- script.js: mobile menu and current year

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html, or open it with Chrome.
4. Internet is needed for the optional Google Fonts import; the site itself works without it.
